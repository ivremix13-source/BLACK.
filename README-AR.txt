BLACK ARENA — دليل التشغيل
===========================

محتويات المشروع:
- index.html          الصفحة الرئيسية
- sensitivity.html   مختبر الحساسية (قيم توضيحية قابلة للتفاعل)
- aim.html            دليل إعدادات التحكم
- devices.html        مكتبة فئات الأجهزة مع البحث والتصفية
- performance.html    دليل الأداء وقائمة تحقق تفاعلية
- guides.html         دليل اللاعب
- about.html          عن BLACK ARENA
- contact.html        روابط التواصل
- style.css           التصميم المشترك المتجاوب
- script.js           التفاعلات المشتركة
- assets/             مكان اختياري لإضافة صورك المحلية لاحقًا

التشغيل:
1. ارفع الملفات إلى مستودع GitHub.
2. في Vercel اختر Import Project ثم مستودع GitHub.
3. لا تحتاج إلى Build Command أو قاعدة بيانات لهذا الإصدار الثابت.
4. اجعل index.html في جذر المشروع كما هو.
5. بعد تعديل الملفات في GitHub، احفظ Commit؛ سيعيد Vercel النشر تلقائيًا إذا ربطت المستودع.

الصور:
- الصور الفنية لـ Free Fire في هذا النموذج تُحمّل من CDN المستخدم في معرض Garena الرسمي.
- المصدر الرسمي: https://ff.garena.com/en/wallpaper/
- يلزم اتصال إنترنت لعرض الصور وخطوط Google Fonts. يُفضّل تنزيل الصور المسموح باستخدامها ووضعها داخل assets إذا أردت الاعتماد على ملفات محلية.
- شعارات Free Fire والعلامات التجارية ملك لأصحابها. BLACK ARENA مشروع مجتمعي غير تابع رسميًا لـ Garena.

الأمان والحدود:
- هذا موقع Front-end ثابت، ولا يحتوي على تسجيل دخول أو قاعدة بيانات أو تخزين بيانات شخصية.
- لا تضع كلمات مرور أو مفاتيح API أو بيانات سرية داخل JavaScript أو HTML؛ كل ما في ملفات الواجهة يستطيع الزائر رؤيته.
- روابط التواصل الخارجية تستخدم target="_blank" مع rel="noopener noreferrer".
- إعدادات الحساسية داخل الصفحة أمثلة توضيحية فقط وليست توصيات مضمونة لكل جهاز أو إصدار لعبة.
